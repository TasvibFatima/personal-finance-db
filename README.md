# Personal Finance & Budget Management System

A relational database project built for managing personal finances.

## About

This project was built as part of my Database Systems course at the 
University of Lahore. It covers the full database design for a web-based 
finance tracker where users can manage income, expenses, budgets, and 
generate financial reports.

## Features

- Track income and expenses
- Manage multiple accounts (Bank, JazzCash, Cash)
- Set monthly budgets per category
- Generate financial reports
- Admin and user roles

## Database Structure

- 10+ entities including User, Account, Transaction, Budget, Income, Expense, Report
- Primary and foreign key constraints
- ERD and Enhanced ERD designed
- Sample data included
- Useful SQL queries included

## Tables

User, Admin, Account, Category, Transaction, Budget, Income, Expense, Report, Notification

## Tech Used

- SQL (MySQL)
- Database Design
- ERD & EERD Modeling
